# PS (Project System)
#### Информационная система для организации и управления научной и проектной деятельностью образовательной организации. (MVP)

### Цель проекта
Внутреннее веб-приложение для образовательной организации (вуз / колледж), автоматизирующее полный цикл управления научной и проектной деятельностью студентов и преподавателей.

### Основные роли:
**Преподаватель (teacher)** — инициатор и руководитель проектов, управляет своими проектами и командами.<br>
**Студент (student)** — исполнитель задач в рамках проектов, видит только свои проекты и задачи.<br>
**Администратор (admin)** — управление пользователями и надзорная роль, полный доступ.<br>
